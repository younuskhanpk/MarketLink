# MarketLink

A professional responsive agriculture marketplace for local produce, built with Node.js + Express.

## Features
- Public landing page with hero, featured markets, farmers, products
- Market and farmer discovery pages
- Product browsing with filters
- Customer, farmer, and admin role views
- Pre-order and pickup flow
- Review and favorites system
- Mobile responsive design
- Demo data and role-based dashboards

## Run locally

```bash
npm install
npm start
```

Then open: http://localhost:3000
